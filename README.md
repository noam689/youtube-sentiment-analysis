# YouTube Sentiment Analysis

Machine Learning & NLP project for classifying YouTube comments into sentiment categories.

## Project Goal
The goal of this project was to build a model that predicts whether a YouTube comment is:
- Positive
- Negative
- Neutral

## Technologies Used
- Python
- pandas
- numpy
- scikit-learn
- matplotlib
- NLP
- TF-IDF
- Logistic Regression
- Linear SVM

## What Was Done
- Data cleaning and preprocessing
- Text vectorization using TF-IDF
- Feature engineering
- Model training and evaluation
- Cross validation
- Overfitting analysis
- Data drift analysis between older and newer years

## Main Insight
The project showed how changes in data distribution over time can affect machine learning performance, especially in NLP tasks.

## Results
The best model achieved a Precision Macro score of approximately 0.59 on unseen future-year data.
